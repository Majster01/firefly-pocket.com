Firefly Pocket on Hetzner

Answer three questions, paste the result into Hetzner's server form, point your domain at the server, and finish in your browser. No SSH.

Before you start

  • Your bank must be covered by Enable Banking. Check it first, before you pay for a server: it is how Firefly Pocket imports your transactions.
  • A domain you control, where you can add a DNS record. A subdomain such as money.example.com works.
  • A Hetzner Cloud account.
  • Later, in the console: an Anthropic or Gemini API key for category suggestions.

1. Your answers

Everything you type stays in this page. It is not sent anywhere, and the page loads no outside scripts.

The five addresses Firefly Pocket answers on are built from it: admin., app., firefly., import. and legal. in front.

Your Firefly III login, and where Let's Encrypt sends certificate notices.

Filled from your browser. The nightly backup (02:00) and import (03:00) run in it.

Advanced: an SSH key

Leave empty if you will not use SSH: it is the only way back in if something goes wrong that the console cannot fix. The server never accepts passwords.

2. Keep your setup code, copy the cloud config

Your setup code

Save it somewhere now, for instance in your password manager. You type it at admin. in step 4. It belongs to the cloud config below: both came from this page load, so if you reload the page, use the new pair.

Lost it? Delete the server and start again from this page. Nothing is on it yet, so it costs a few minutes.

Your cloud config

3. Make the server

In the Hetzner Cloud Console, add a server. Hetzner's wording may differ a little.

  1. Location: one in the EU keeps your data there (Falkenstein, Nuremberg or Helsinki).
  2. Image: Ubuntu 24.04.
  3. Type: CX23 (2 vCPU, 4 GB). The whole stack idles around 1.5 GB.
  4. Networking: keep a public IPv4 address. Your bank connection and the backups need it.
  5. SSH keys: none, unless you filled in the advanced field. Hetzner then emails you a root password. You do not need it: the server refuses passwords over the network. It only works on Hetzner's web Console, if you ever need to look inside.
  6. Firewall: make one that allows incoming TCP 80, TCP 443 and UDP 443, and nothing else. Add TCP 22 only if you gave an SSH key.
  7. Cloud config: paste what you copied in step 2.
  8. Create the server and copy its IPv4 address.

4. Point your domain at it

At your DNS provider, add this one record. Paste the server's address to see it with your domain.

*.<your domain>    A    <server address>

The wildcard covers all five addresses. A DNS provider without wildcard records needs the five as separate A records. The server waits for admin. to point at it before it asks Let's Encrypt for certificates, so the order does not matter.

Then open the console

Give it about 5 to 10 minutes after the DNS record is live. Open https://admin.<your domain> and enter your setup code. The console takes you through the rest: your Firefly III account, your bank, category suggestions, alerts and backups.

If it does not open

  • Check that the DNS record is live: admin. in front of your domain should resolve to the server's address.
  • Still nothing after 20 minutes: in Hetzner, open your server and its Console. The login screen says where the setup stands.
  • Made a mistake in the answers? Delete the server and make a new one with a new cloud config from this page.
